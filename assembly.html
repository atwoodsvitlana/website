Assembly: Endgame

React JavaScript HTML5 CSS3
View GitHub Live Demo

Overview

A word game powered by React.

Assembly: Endgame is a browser-based word-guessing game built as part of the Scrimba Frontend Developer course. Players must uncover a hidden word by guessing individual letters within a limited number of attempts.

The application provides visual feedback for correct and incorrect guesses, allowing players to follow their progress as the game develops. Its interface updates dynamically in response to user interactions and the current state of the game.

Building this project strengthened my understanding of React fundamentals, including state management, event handling, component structure, and conditional rendering. It also helped me practice organizing game logic and keeping the interface synchronized with changing application state.

Key Features

  • Interactive letter guessing
  • User input and event handling
  • Dynamic game state management
  • Conditional UI rendering
  • Visual feedback for guesses
  • Win and loss game states
  • Interactive browser-based gameplay

Built With

React · JavaScript · HTML · CSS
