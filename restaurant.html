Overview

Making recipe discovery simple.

Recipe Explorer is a responsive web application that helps users discover recipes, explore different cuisines, and find meals that match their preferences. Using the DummyJSON Recipes API, the application dynamically retrieves and displays recipe data in an organized, easy-to-navigate interface.

Users can search for recipes, filter results by category and cuisine, sort recipes by name or rating, and navigate through paginated results. The application also includes recipe details, a favorites feature, and local storage to preserve saved recipes between visits.

Building this project strengthened my understanding of asynchronous JavaScript, API integration, array methods, event handling, and dynamic DOM manipulation. It also challenged me to coordinate search, filtering, sorting, and pagination while keeping the interface responsive and the user experience consistent.

Key Features

  • Recipe search
  • Category and cuisine filters
  • Sorting by name and rating
  • Recipe details view
  • Favorites saved with localStorage
  • Paginated recipe results
  • Responsive layout
