Tenzies

An interactive dice game built with React, combining simple game logic with dynamic, state-driven gameplay.

React JavaScript HTML5 CSS3
View GitHub Live Demo

Overview

A simple game with interactive logic.

Tenzies is an interactive dice game built as part of the Scrimba Frontend Developer course. The goal is to roll the dice until all values match, holding individual dice between rolls to keep the values you want.

The application responds to player interactions by updating dice values and their held states. React dynamically renders these changes, allowing players to track their progress throughout the game.

Building this project strengthened my understanding of React fundamentals, including component state, props, event handling, and conditional rendering. It also reinforced the importance of immutability when updating state and keeping the interface consistent with the underlying game logic.

Key Features

  • Interactive dice rolling
  • Hold individual dice between rolls
  • Dynamic state updates
  • Reusable React components
  • Props and event handling
  • Conditional rendering
  • Goal-based game logic

Built With

React · JavaScript · HTML · CSS
